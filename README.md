# Simple Rock-Paper-Scissors Game

A simple Rock-Paper-Scissors game built with HTML, CSS, and JavaScript.  
Players can choose between Rock, Paper, or Scissors, play against the computer, and see their match history stored in localStorage.

## Features

- Play Rock, Paper, Scissors against the computer
- Shows the result of each match (win, lose, draw)
- Tracks match history in localStorage
- Simple responsive design

## How to Use

1. Open `index.html` in a browser
2. Click on Rock, Paper, or Scissors to play
3. Check your match history displayed in the table
